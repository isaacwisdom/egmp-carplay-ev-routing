# Kia EV6 US — copied, unvalidated values

Installer-enabled for CVEV USA 260507 only when the HMG-API map and exact native hashes pass. Numerical battery, connector and contract values are copied from the Ioniq 5. They are unvalidated for EV6 and likely inaccurate. Vehicle identity fields differ; that does not establish EV6 hardware compatibility or calibration.
